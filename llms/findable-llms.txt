# Findable

> Findable is an AI-powered building intelligence platform (findable.ai) that makes construction and property documentation searchable, structured, and audit-ready. It classifies building documents against standards like BS 9991 and NS 3451, detects missing or expiring documents, supports Golden Thread / Building Safety Act compliance, and answers natural-language questions across a building's documentation. It offers a Partner API, a hosted MCP server, and official TypeScript SDK and React libraries.

## APIs

- [Findable Partner API](https://docs.findable.ai): REST API for document search and AI Q&A across building documentation (base URL https://api.findable.ai)
